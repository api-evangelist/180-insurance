- Cotações
  - [Efetuar cotações.](https://docs.180s.com.br/reference/post_sagas-v1-cotacoes.md): Endpoint usado para cotar o seguro de acordo com o risco informado e coberturas escolhidas.    Para criação de um proposta será necesário informar o ID de um **Combo de Produto** e o ID de um…
  - [Obter detalhes de uma cotação.](https://docs.180s.com.br/reference/get_sagas-v1-cotacoes-id-cotacao.md): Endpoint utilizado para retornar os detalhes de uma cotação através do seu ID.
- Propostas
  - [Criar propostas.](https://docs.180s.com.br/reference/post_sagas-v1-propostas.md): Endpoint usado para realizar a emissão de uma proposta.    Para realizar a emissão de uma proposta será necessário informar o ID de uma cotação. O campo opcional `id-proposta-parceiro` identifica de…
  - [Obter detalhes de uma proposta.](https://docs.180s.com.br/reference/get_sagas-v1-propostas-id-proposta.md): Endpoint utilizado para retornar os detalhes de uma determinada proposta.
  - [Atualizar uma proposta existente.](https://docs.180s.com.br/reference/patch_sagas-v1-propostas-id-proposta.md): Endpoint utilizado para atualizar uma proposta existente.
  - [Solicitar cancelamento de proposta por id](https://docs.180s.com.br/reference/post_sagas-v1-propostas-id-proposta-solicitar-cancelamento.md): Endpoint utilizado para cancelar uma proposta.    Para que seja possível cancelar uma proposta, a mesma deve estar no status `pendente`.
  - [Obter documento referente à proposta.](https://docs.180s.com.br/reference/get_sagas-v1-documentos-propostas-id-proposta-produtos-id-produto.md): Obter o documento de uma proposta gerada.    A resposta desse endpoint será em um formato de documento, contendo o header `Content-type: application/pdf`.
  - [Atualizar dados do cliente-segurado (proposta pendente)](https://docs.180s.com.br/reference/patch_sagas-v1-propostas-id-proposta-cliente-segurado.md): Endpoint que permite atualizar dados do cliente segurado enquanto a proposta está pendente. Alterações em uma proposta completa são feitas por endossos na venda correspondente.
  - [Reenviar uma comunicação de proposta](https://docs.180s.com.br/reference/post_sagas-v1-propostas-id-proposta-reenviar-comunicacao-comunicacao.md): Endpoint que permite reenviar uma comunicação de proposta (como termos e condições), quando aplicável
  - [Obter boleto.](https://docs.180s.com.br/reference/get_sagas-v1-boleto-payment-intent-id.md): Retorna o PDF do boleto. Caso o documento ainda esteja sendo gerado, responde 204 — o cliente deve tentar novamente em seguida.
